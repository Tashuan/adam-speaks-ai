# Admin Console guide

The Admin Console is the owner workspace for every avatar — navigation, dashboard, per-avatar overview, avatar creation (builder, clone, templates), account and billing, credits, and usage dashboards.

Key surfaces:

- **Dashboard (Home)** — cross-avatar sessions, chats, and usage; credits and Re-Up; per-avatar preview tiles.
- **Overview** — per-avatar setup, preview, share link, and public visibility (leaderboard opt-out).
- **Action row** — Preview, New Avatar, Show My Avatars, and Share Link (copies the standalone `/avatar/{slug}/{avatarId}` URL).
- **My Account** — plan, billing history, Stripe portal, credit Re-Up, and your public user slug.

Live guide: https://adam-speaks.com/guides/console
