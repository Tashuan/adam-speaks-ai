# Animation authoring guide

The Animations workspace covers the full motion lifecycle:

- **My Library** — import FBX clips; processed into runtime animations.
- **Avatar Clips** — assign library clips to the avatar's behavior slots.
- **Profiles** — named assignment sets that switch the avatar's motion personality.
- **Snippets & Clip Mixer** — compose new animations on a timeline: trimming, crossfades, loop seams, speed/intensity/smoothing, root locking; saved with provenance.
- **Playback** — global blending, looping, and speech-reactive motion tuning.

Live guide: https://adam-speaks.com/guides/animation-authoring
