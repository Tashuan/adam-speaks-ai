# Scene & appearance guide

Everything visual about the avatar and its surroundings:

- **Scene → Avatar** — placement, framing, and scale in the viewer.
- **Scene → Media** — image or looping-video background behind the avatar.
- **Outfits** — published material/outfit variations; locked variants unlock permanently for 100 credits.
- **Props** — reusable 3D assets placed in the scene.
- **Expressions** — saved facial expressions organized by rig, authored in the Avatar Preview GUI.

Live guide: https://adam-speaks.com/guides/scene
