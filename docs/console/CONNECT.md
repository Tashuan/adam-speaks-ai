# Connect guide

Remote control for a running avatar (Integrations → Connections):

- **Sessions** — every open embed or standalone viewer is a targetable session; pin one with `?sid=` on the avatar URL.
- **Speak & control** — send text to the selected viewer through the same speech lifecycle as REST/WebSocket/MCP transports.
- **Event stream** — SSE stream of speech progress and viewer state, with reconnect controls.
- **Embed Usage** — per-avatar session history, durations, and communication logs.

Live guide: https://adam-speaks.com/guides/connect
